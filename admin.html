Матеріали для брокерів

Посилання з UTM-мітками — у Google Analytics видно, що брокер прийшов із запрошення.

Як працювати
  1. Додайте брокерів — вручну або списком.
  2. «Написати» → оберіть шаблон → канал: WhatsApp, Viber, Telegram, Email.
  3. Статус і дата контакту оновлюються самі.
  4. Коли брокер зареєструється з тим самим email чи телефоном — статус стане «Зареєструвався».

Консультації брокерів

Безкоштовні консультації для платних тарифів. Бухгалтерські питання — для clerk.tax, юридичні — для «Адвокат Поруч». Відповідь, яку ви тут збережете, брокер побачить у кабінеті.

Заявки RMPD

🧪 Подати тестову заявку

Порядок: «В роботі» → внести дані на puesc.gov.pl (форма RMPD100, для оновлень — «RMPD – Aktualizacja») → вписати номер RMPD → «Зареєстровано». Номер діє 10 днів, «Діє до» підставиться автоматично. Якщо дані неповні — «Потрібне уточнення» з коментарем: клієнт отримає його в кабінеті та Telegram. Кожне поле можна скопіювати кліком.

Заявки SENT

🧪 Подати тестову заявку

Порядок: «В роботі» → на puesc.gov.pl відкрити форму доповнення перевізником (SENT-301 / 202 / 102 — вказано в заявці), ввести номер SENT і ключ KD-…, внести дані → після підтвердження PUESC поставити «Подано в PUESC». Якщо номер або ключ не приймаються — «Потрібне уточнення» з коментарем. Ціни SENT — у розділі RMPD → «💳 Ціни й баланси клієнтів».

Відрядження водіїв

🧪 Подати тестову заявку

Порядок: перевірити, що є підписана довіреність клієнта (фото/скан — у Telegram або пошті) → «В роботі» → biznes.gov.pl → «Załatw online», увійти (Profil Zaufany або «Zaloguj się przez e-mail»), пройти майстер (поля нижче в тому ж порядку, копіюються кліком), додати довіреність → «Podpis kwalifikowany» → «Pobierz dokument» → підписати файл у proCertum SmartSign / SimplySign (формат XAdES, внутрішній, SHA-256) → «Dodaj podpisany dokument» → «Wyślij», не пізніше дати початку → «Подано до PIP». Підписаний файл після підпису не відкривати. PIP підтвердження не видає — збережіть UPO/квитанцію з Biznes.gov.pl.

Ліцензовані перевізники — Укртрансбезпека

Відкритий реєстр ліцензій (data.gov.ua, CC BY 4.0). У реєстрі є лише назва й код ЄДРПОУ / ІПН — телефони й email доведеться знайти: у нотатці кожного контакту буде посилання на картку компанії в Opendatabot.

Спершу додаються компанії з найновішими ліцензіями. Ті, що вже є в базі (за ЄДРПОУ), пропускаються.

Імпорт списку
По одному брокеру в рядку. Поля розділяйте табуляцією (вставка з Excel / Google Таблиць) або крапкою з комою. Телефон, email, Telegram і область розпізнаються автоматично; перше текстове поле — назва, друге — місто.
Шаблони повідомлень
Підстановки: {профіль} — сторінка компанії з реєстру; {, імʼя} — «, Олександр» або нічого; {імʼя}; {компанія}; {місто}; {речення_про_регіон}; {презентація}; {інструкція}; {реєстрація}; {сторінка_області}.
