Платіжна інтеграція
Ключі WayForPay зберігаються на сервері й у браузер не потрапляють. Змінити їх можна лише через CLI:

supabase secrets set WFP_MERCHANT=…
supabase secrets set WFP_SECRET=…

Стан функції: перевіряємо…
Ніколи не вводьте Secret Key у форму на сайті. Будь-яке поле в браузері означає, що ключ можна прочитати з коду сторінки або з локального сховища.
Запросити брокера
Брокер отримає лист із посиланням. Профіль з'явиться в каталозі лише після того, як він підтвердить дані.
Послуги
